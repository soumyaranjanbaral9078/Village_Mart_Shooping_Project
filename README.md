# 🌿 Village Mart – Online Shopping Website
Online Shopping Web App 

**Village Mart** is a frontend-based online shopping website developed using HTML, CSS, and JavaScript. It provides a simple and user-friendly shopping experience where customers can browse products, search items, add products to their cart, and proceed to checkout.

## 🚀 Features

- 🏠 Attractive homepage with a green and white theme
- 🛍️ Product catalog with 100 sample products
- 🔍 Search products by name
- 📂 Filter products by category
- 🛒 Add to Cart functionality
- ➕ Increase and decrease product quantity
- ❌ Remove products from cart
- ☑️ Select and deselect cart items
- ⚡ Buy Now functionality
- 👤 Login popup (frontend demo)
- 💳 Checkout with demo payment options
- 🧾 Order invoice and print option
- 💾 LocalStorage support for cart data

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure |

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the VillageMart folder.
3. Open `index.html` in your browser.
4. Start exploring the Village Mart website.

You can also run the project using the **Live Server** extension in Visual Studio Code.

## 🛒 Shopping Process

1. Open the Village Mart website.
2. Browse available products.
3. Search or select a product category.
4. Click Add to Cart.
5. Open the shopping cart.
6. Select the products you want to purchase.
7. Click Checkout.
8. Enter customer details and select a demo payment option.
9. View and print the invoice.

## 🔐 Login Information

The current login feature is a frontend demonstration only. It does not use a real database or secure user authentication.

## 💳 Payment Information

Payment options are for demonstration purposes only. No actual online payment is processed.
